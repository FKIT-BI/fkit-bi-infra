# DEMO-003 — наполнение демо-стенда телеметрией

## Scope

`scripts/demo_generate.py` наполняет демо-предприятия из Analytics-релиза `015-demo-enterprises` через публичные
Analytics и Generator API: активирует шесть демо-сценариев, генерирует историю каждого циклического сценария от
начала покрытия машин до текущего момента (последовательно — генератор держит один исторический прогон), догоняет
минуты, занятые самой историей, и запускает бесконечный realtime. Режим `--live-alarm` проводит 11-минутный показ
перегрева гомогенизатора и возвращает варочный участок в realtime. Инструкция и сценарий показа — `docs/demo.md`.

## Decisions

- Только публичный API и стандартная библиотека Python: скрипт не пишет в БД и запускается с Dev-хоста или рабочей машины.
- Учётные данные: `FKIT_DEMO_*`, затем `FKIT_BOOTSTRAP_*` из `infisical run --path=/github-actions`, иначе интерактивно;
  пароль не выводится. JWT перевыпускается по 401 — наполнение длится дольше 30 минут.
- Повторный запуск безопасен: сценарии с идущим realtime пропускаются, начало истории — максимум из начала покрытия и
  уже сгенерированного (`eventTo` завершённых историй, `generatedThrough` прочих прогонов), поэтому заполняется
  только пропуск. `HISTORICAL_CAPACITY_BUSY` ожидается и повторяется.

## Verification

- Полная репетиция на локальном стенде (Analytics `d575e56`, Generator `0bf4625`, чистая БД, сид применён при старте):

## Rehearsal results (local stack, 2026-10-14)

- Наполнение: 75 минут, 6,5 млн измерений (около 1500/с), пять историй по 169–170 ч и короткие догоняющие
  прогоны, затем пять realtime-прогонов. Повторный запуск пропустил все сценарии.
- Найдено и исправлено в Generator (`fix(generator): let more than four endless realtime runs work at once`):
  пул realtime-потоков был жёстко 4, пятый бесконечный прогон оставался `QUEUED`. Теперь
  `generator.realtime.workers`, по умолчанию 8; после перезапуска генератора все пять прогонов продолжили работу.
- Неделя по машинам: у всех 168 ч без «нет связи». OEE — линия туб ≈90%, линия кремов ≈70%, варочный участок
  65–74%, линия шампуней ≈50% (62 отказа моноблока, MTTR этикетировщика 28 мин), склад ≈53–55% (ночной простой).
- `--live-alarm`: остановка realtime участка около 20 с, температура гомогенизатора до 97 °C, авария 4 минуты, затем
  работа; участок вернулся в realtime.
