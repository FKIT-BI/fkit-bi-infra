# Digest — self-hosted data boundary and operations

- **Claim:** Infisical's published self-host path is Docker Compose; the stack includes the application, PostgreSQL, and Redis. PostgreSQL is described as source of truth for secrets, accounts, projects, and audit logs; Redis is cache/background processing. **Source:** Infisical, “Self Host Infisical with Docker Compose,” undated video transcript, accessed 2026-10-12, https://infisical.com/videos/self-host-infisical. **Confidence:** medium (vendor implementation guidance).
- **Claim:** The self-hosted secret database depends on an operator-controlled `ENCRYPTION_KEY`; the official deployment walkthrough warns that database recovery without this key cannot decrypt secrets. The key and DB backup must therefore be treated as a matched recovery set. **Source:** same official deployment walkthrough, accessed 2026-10-12. **Confidence:** medium.
- **Claim:** The current Infisical server source defaults `TELEMETRY_ENABLED=true` and points PostHog at `https://app.posthog.com`; it also defaults `ANNOUNCEMENTS_ENABLED=true` and explicitly comments that self-hosted operators can disable outbound calls with `ANNOUNCEMENTS_ENABLED=false`. Thus “self-hosted” alone is not evidence of zero outbound requests. **Source:** Infisical, backend env config, current `main`, accessed 2026-10-12, https://github.com/Infisical/infisical/blob/main/backend/src/lib/config/env.ts. **Confidence:** high (primary source code).
- **Claim:** The same source has a separate OpenTelemetry collection switch defaulting to false, but this does not override the product telemetry switch above. For a conservative first deployment, explicitly set both telemetry-related flags off and announcements off, then verify outbound requests at the host firewall/log layer. **Source:** same source code. **Confidence:** high for config defaults; medium for resulting zero-egress outcome (not proven by config inspection alone).
- **Open question:** Other optional features, licensing/entitlement checks, image pulls, GitHub OIDC key discovery, email, or user-enabled integrations may make outbound calls. No absolute zero-egress claim is made; observe egress during test and whitelist required endpoints only if practical.
