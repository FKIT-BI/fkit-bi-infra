- (decision by analyst) MVP backup: nightly PostgreSQL custom-format backup, seven local restore points, file permissions restricted to service operator; RPO <=24h and manual restore target <=4h. No PITR/HA/automated failover. Run outside peak with bounded resources and alert on missed backup; verify restore before releases. Raw partitions expire only when upper bound <= now()-90d, partition DDL/cleanup outside ingest transactions; pre-create seven days ahead and do not drop data while dirty work references it.
- (decision by analyst) MVP logs: single-line JSON to stdout with timestamp, level, service, event, traceId and message; server generates request trace UUID, returns X-Trace-Id and includes same identifier in errors. Durable asynchronous jobs carry correlationId plus jobId/runId/machineId as structured fields. Never log credentials, JWTs, passwords, raw telemetry values or unbounded user payloads; domain identifiers are not metric labels.
- (decision by analyst) Acceptance strategy is contract-first but avoids duplicating each endpoint prose: every OpenAPI operation gets automated schema/auth/status/error contract coverage; each end-to-end user command gets Given/When/Then acceptance cases linked to operationIds. Use exact numeric, state-time, late-data, scheduled-run, incident-idempotency, hierarchy and stale-read examples in companion catalog.
- (event) Acceptance and verification package initialized from accepted specifications; implementation has not started.
