# Development

Use BMAD Core 6.12.0 from the workspace root. Read `docs/bmad/project-context.md` before planning. A cross-service task has a shared ID in infra and linked local tasks in the participating repositories; record implementation, merge, verification and Dev deployment separately.

`main` is the baseline; pull requests and integration target `develop`. A push to `develop` checks and delivers the changed component to Dev.
